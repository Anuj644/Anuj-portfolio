- HTML5
- CSS3 (custom properties, grid, flexbox, responsive layout)
- Vanilla JavaScript (interactive network animation in the hero section, mobile menu)
- Google Fonts: Bricolage Grotesque and Instrument Sans

## Run it locally

1. Clone the repository

   ```
   git clone https://github.com/Anuj644/Anuj644.github.io.git
   ```

2. Open the folder

   ```
   cd Anuj644.github.io
   ```

3. Open `index.html` in your browser. No build step or dependencies are needed.

## Features

- Fully responsive on mobile, tablet and desktop
- Animated hero background that reacts to the mouse
- Respects the reduced motion setting for accessibility
- Keyboard-friendly navigation with visible focus states
- Fast loading, with no frameworks or external libraries
